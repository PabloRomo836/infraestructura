# Lab 02 - Servidor Web

## Objetivo

Crear y publicar una página web sencilla utilizando un servidor web Nginx.

## Entorno utilizado

* Windows 10
* WSL2
* Debian
* Docker
* Nginx
* HTML

## Archivos

* `index.html` → página web utilizada durante la práctica.
* `README.md` → documentación del laboratorio.

## Práctica realizada

Durante este laboratorio se creó una página web HTML y se preparó el entorno para servirla mediante Nginx.

La práctica permitió comprender la relación entre:

* Página web
* Servidor web
* Contenedor
* Puerto de acceso

## Resultado

La página web pudo ser ejecutada y visualizada correctamente desde el navegador.

## Aprendizajes

* Concepto básico de servidor web.
* Uso de Nginx.
* Relación entre archivos HTML y servidor web.
* Acceso a servicios mediante puertos.
* Primeros pasos con servicios ejecutados en contenedores.
